plone.app.workflow: 6.0.0 → 7.0.0a2
-----------------------------------
Breaking changes:

- Move the classic UI sharing page template and form handling to ``plone.app.layout``.
  The ``SharingView`` in ``plone.app.workflow`` now provides only the data/API methods;
  the base ``__call__`` raises a ``ValueError`` directing integrators to use the
  ``SharingView`` override registered for ``plone.app.layout.interfaces.IPloneAppLayoutLayer``.
  Classic UI installations must depend on a ``plone.app.layout`` version that ships this override.
  The ``updateSharingInfo`` view and the ``Products.statusmessages`` dependency are removed.
  [MrTango] (#3953)

New features:

- Fire ``PrincipalLocalRolesModifiedEvent`` for each user or group whose local roles the sharing view changes, with the roles before and after, and ``LocalRolesInheritanceModifiedEvent`` when it switches inheriting local roles on or off.
  Audit logging needs these to record privilege changes, as required by the NIS2 directive.
  [jladage] (#93)

Internal:

- Move package metadata from ``setup.py`` to ``pyproject.toml``.
  [plone devs]

plone.restapi: 10.2.1 → 10.3.0
------------------------------
New features:

- Updated support for blocks-based content to be compatible with the evolving support for the Plate editor in Aurora and volto-plate. Plate regions (stored with the `plate` block type and keyed by region name) are handled in the block visitor, the `SearchableText` indexer, and link integrity checks. The legacy `__somersault__` block type is deprecated. Add-ons can check for the new `plonerestapi-plate-regions` ZCML feature. @sneridagh #2092

Internal:

- Update CI configuration to test Python 3.11 as the minimum version for Plone
  6, and run Plone 5 tests using the ubuntu-24 runner. @davisagli


plone.staticresources: 3.0.10 → 3.1.0a3
---------------------------------------
New features:

- Change the update method to download bundles.

  Change the method to update Mockup, Bootstrap Icons and Country Flags to
  download bundles.

  The new installation method does not use webpack build but downloads releases
  from GitHub. This is much faster and more reproductible - updating the build
  dependencies and the build step itself is now obsolete.

  The Makefile targets are inspired from plone.patternslib.

- Update Mockup to 5.7.0-alpha.3.

- Add Svelte 5 folder-contents pattern `pat-filemanager`

  A plone.restapi-only rewrite of pat-structure's folder contents, built on
  Svelte 5 runes. Table and photo-grid views; selection, clipboard
  (cut/copy/paste), delete with link-integrity check, drag-and-drop
  reordering and drag-into-folder; multi-upload via @tus-upload — including
  dropping a whole folder to recreate its tree behind a preview/approval
  step; in-app folder browsing with breadcrumbs and live header sync; column
  configuration, free-text and advanced querystring filtering; batch actions
  (workflow, tags, properties, rename); cookie persistence, i18n and
  accessibility. No Backbone, underscore, DataTables or custom Plone views.

Bug fixes:

- Add missing icons to the registry.
  Also provide a upgrade utility to add any missing icons in the future.
  @thet

- Remove unused requirements.txt file.

- Update scripts: Improve update-icons target.

  Use a virtual environment and install lxml for the update-icons target to make
  it work without manually installing dependencies.

- Update scripts: Use pathlib to construct filesystem paths.

Documentation:

- Update the version information in the README. @petschki

Internal:

- Update GitHub action dependencies. @thet

- Raise metadata.xml version to 300 to separate that from the 3.0.x branch.
  @thet

z3c.form: 6.1 → 6.2
-------------------
- utils changedField: Compare also for timezone equality.
  When saving a new value for a datetime field with a different timezone but
  the same offset, ``utils.changedField`` was preventing to recognize the
  change. Now it is - datetime values which resolve to the same date, time and
  UTC offset but are in a different timezone are now considered not the same
  value.
  (`#136 <https://github.com/zopefoundation/z3c.form/issues/136>`_)

- ``OrderedSelectWidget`` now shows the selected items of its current value,
  even when the value is set after ``update()``. Inside an ``ObjectWidget``
  the saved selection was not displayed.

- Add support for Python 3.15.

- Drop support for Python 3.10.
