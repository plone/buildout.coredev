Introduction
============
This repository contains the development buildout for Plone Core (the backend and classic UI).
You are on the version 6.2 branch.

For the latest contributor guidance and setup options, please see `README.md <README.md>`_.
It includes links to the official Plone contributor documentation, the Makefile-based workflow in `README-make.md <README-make.md>`_, and container/Codespaces setup in `README-devcontainer.md <README-devcontainer.md>`_.

If this is your first time here, please read all instructions on `docs.plone.org <https://6.docs.plone.org/contributing/core/index.html>`_ before getting started.

It will save you time in the end, we promise!
