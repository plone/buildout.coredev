Fix scale caching when _p_mtime is None

For unsaved persistent objects (common in tests), _p_mtime is None.
DateTime(None) returns "now", so every call to modified() produced a
different timestamp and cached scales were never reused.

Fall back to 0 (epoch) when mtime is None, giving a stable value
that allows the scale cache to work correctly.

Fixes #58
