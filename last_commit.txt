This avoids an error while releasing:

```

```

Alternatively, we would need to update `constraints.txt` to use Plone 6.0-dev (or 6.1-dev), which has a newer version pin for `twine`:
`twine` 6.1.0+ can handle the metadata generated by setuptools 77.
