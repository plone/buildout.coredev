Fix CI on the Ubuntu 26.04 ubuntu-latest runner

GitHub's ubuntu-latest moved to Ubuntu 26.04, where the Playwright
release pinned by Plone's constraints (robotframework-browser 19.10.1)
refuses to install chromium, so `rfbrowser init` fails before any test
runs. Set PLAYWRIGHT_HOST_PLATFORM_OVERRIDE=ubuntu24.04-x64 through the
plone/meta `[tox] test_environment_variables` option, so Playwright
installs its Ubuntu 24.04 builds. This fixes both the Tests matrix and
the shared plone/meta coverage workflow, which runs `tox -e coverage`.

Test against Plone 6.2-dev constraints

constraints.txt still pointed at the Plone 6.1-dev constraints, so the
"6.2" test jobs actually installed Plone 6.1 and robotframework-browser
19.10.1. That release's Playwright (1.56) refuses to install chromium on
the Ubuntu 26.04 ubuntu-latest runner. The 6.2-dev constraints pin
robotframework-browser 20.6.0 (Playwright 1.63), which supports it.

Drop the PLAYWRIGHT_HOST_PLATFORM_OVERRIDE workaround.
