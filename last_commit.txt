Fix path criteria when the virtual root is above the portal

Since 3.1.0 paths are translated from the virtual hosting root. With
the VirtualHostRoot at the Zope root (site reachable as /Plone)
physicalPathFromURL returns a portal relative path unchanged, and it
was used as physical path: the query matched nothing and
folder_contents stayed empty.

Only accept the translated path when it lies inside the portal,
otherwise fall back to prepending the root as before.
