Replace jstz with native Intl API for timezone detection

The jstz library (v1.0.4, from 2012) could only distinguish timezones
by UTC offset and DST behavior. All UTC+1/DST countries (France, Belgium,
Netherlands, Italy, Spain) were mapped to Europe/Berlin.

The native Intl.DateTimeFormat().resolvedOptions().timeZone API returns
the correct IANA timezone from the browser/OS, supported by all modern
browsers.

Fixes #2951
