Translate virtual hosting paths to physical paths in path criteria

Behind a Virtual Host Monster clients (e.g. pat-filemanager via
plone.restapi's @querystring-search) send the URL path, which is relative
to the virtual root. `_pathByRoot` prepended the navigation root or portal
path instead, which only works if both roots coincide. Subsites or language
folders as virtual root, contexts inside a navigation root and `_vh_`
inside-out hosting returned wrong or no results.

Use `request.physicalPathFromURL` when virtual hosting is active and the
path is not already a physical portal path.

See plone/plone.restapi#2023
