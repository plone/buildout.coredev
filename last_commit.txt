Combine the version warning tests into one table.

Each case in VERSION_WARNING_CASES is a dict on one line, with the Python
minor version, the mocked date, and the expected Python and Plone security
warnings.  A separate test method is generated for each case, so when one
case fails, the others still run.

All results are compared at once as a dict, so a failure shows every
difference, plus the Python version and date.  Sample output when changing
the date of one case to 2038-01-01:

```
    AssertionError: {'python_warning()': True, ...} != {'python_warning()': False, ...}
    - {'Python warning shown': True,
    ?                          ^^^

    + {'Python warning shown': False,
    ?                          ^^^^

       'maintenance warning shown': False,
       'plone_maintenance_warning()': False,
       'plone_security_warning()': True,
    -  'python_warning()': True,
    ?                      ^^^

    +  'python_warning()': False,
    ?                      ^^^^

       'release schedule link shown': True,
       'security warning shown': True,
       'version_warning()': True} : Version warnings for Python 3.12 on 2038-01-01
```
