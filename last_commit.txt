Fix #49: Disable additional dates feature in recurrence widget

The additional dates (RDATE) feature causes interoperability issues
with Outlook and Android calendar clients when exporting/importing
iCal events. This change disables the feature by adding
allowAdditionalDates=False to the widget configuration.

- Add allowAdditionalDates=False configuration option to widget
- Update unit test to reflect new configuration
- Add changelog entry documenting the fix
