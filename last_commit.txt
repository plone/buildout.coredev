Fix isDefaultPortrait when the default portrait is not traversable (#2036)

portal.restrictedTraverse(default_portrait, None) returns None when the
default portrait object is missing or not accessible. That None was passed
straight to aq_inner(...).getPhysicalPath(), raising an AttributeError and
turning GET /@users/&lt;userid&gt; into a 500 for any user with a portrait set.

Return False when the default portrait cannot be resolved: a value cannot
equal a default that does not exist.

Adds a unit test for the guard and a functional test covering the 500.

Closes #2035
