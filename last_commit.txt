Fix getattr without default in EXIF loading

getattr(image, "name") raises AttributeError when the image has no
name attribute (e.g. raw bytes from the registry for the site logo).
Add None as default so the fallback to _ensure_data works correctly.

Also replace deprecated log.warn with log.warning and include the
exception in the message.

Fixes #192
