Add aurora profile that removes the Volto personal_tools actions

The personal_tools actions added in 6.1.0 (#218) point to Volto-only
URLs. Plone Aurora reads the same category and, when it has actions,
uses them instead of its built-in links, so its Personal tools menu
breaks. Add a `plone.volto:aurora` profile for Aurora sites, which
depends on the default profile and removes the profile, preferences
and plone_setup actions again. The (now empty) category is kept, so
actions other add-ons add to it stay.

Fixes #219

Set Aurora personal_tools defaults in the aurora profile

Instead of removing the personal_tools actions, the aurora profile now
sets the URLs Plone Aurora's Personal tools menu uses as links, the same
way the default profile does for Volto (#218):

- profile: /@@personal-information
- preferences: /@@personal-preferences (no "component" link target)
- plone_setup: /controlpanel, for "Plone Site Setup: Overview"
- logout: /logout (new)

These match Aurora's built-in fallback links. Volto sites keep the
defaults from plone.volto:default. Add an @actions service test for
member and manager.
