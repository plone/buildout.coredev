Revert "6.2: Remove remaining deprecated Plone 5 resource registry records."

Revert this commit for these reasons:

- It was deleting the `plone.resources.development` registry key. While it is
  barely used having it removed breaks the resource registry when editing
  something through-the-web.

- When adding a bundle via the resource registry all the deprecated keys are
  also imported, even if not used. This is due to the deprecated keys are still
  present in `plone.base.interfaces.resources.IBundleRegistry` schema interface
  definition for BBB compatibility. This should be removed in Plone 7.

This cleanup task can only be applied in the future Plone 7 release.

This reverts commit fa3b1ab712de5186f788d15475c233eb023e2756.
