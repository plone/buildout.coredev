Only mock sys in the overview module, not sys.version_info globally.

Taken over from 6.2, commit d8c83c9fcccefdd3f59d6b13d3a92cef6b6c4177.

Chameleon compares sys.version_info with a tuple when it compiles a
template.  With our MockVersionInfo this raises a TypeError, so the macros
of prefs_main_template were None, and rendering the overview failed with:

    LocationError: (None, 'master')

This happened on GitHub Actions, but not locally with bin/test, because
there CHAMELEON_CACHE is set, so the templates were already compiled.
It also failed when doing this in the coredev buildout:

```
make install
.venv/bin/zope-testrunner --test-path src/Products.CMFPlone -s Products.CMFPlone -m test_controlpanel_overview
```
