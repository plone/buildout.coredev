Add currentUID operation and make path sortable

Add the plone.app.querystring.operation.string.currentUID ("Current
item") operation. It resolves to the UID of the context where the query
runs, so add-ons can filter their relation indexes by the current item.
No core field uses it by default; the README shows how to enable it.

Make the path (Location) field sortable. The catalog path index already
supports sorting by full physical path; only the registry flag hid it.

Bump the profile to version 16 with an upgrade step for existing sites.

Closes #207
Closes #208
