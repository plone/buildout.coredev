Add personal_tools actions for the Volto toolbar

Volto's toolbar Personal tools menu builds its entries from the
personal_tools category of the @actions response (plone/volto#8507).
Add that category with Profile (/personal-information), Preferences
(the "preferences" toolbar panel) and Site Setup (/controlpanel, for
users with "Plone Site Setup: Overview"), plus the 1101 -&gt; 1102
upgrade step that imports them on existing sites.

pytest-plone 1.1 keeps every test layer set up for the whole session,
and the core, coresandbox and migration stacks each created a "plone"
site on the same database, so the suite errored on setup. Each stack
now uses its own site id (volto, coresandbox, plone):
plone.app.testing's PLONE_SITE_ID is swapped while each layer runs its
hooks, and a single robot remote library bundle on Startup replaces
the upstream one, which brought in a second PLONE_FIXTURE site. The
service tests use pytest-plone's request fixtures instead of local
copies.

Closes #217

dependency graph.
