Store only the message in BrokenTransform, not the exception

BrokenTransform kept the exception instance from the failed
_load_transform(). Its traceback references every frame of the request
that loaded the transform, and through f_back every frame above it, all
with their locals. Stored in the volatile _v_transform of a persistent
Transform, this pinned a whole request stack per ZODB connection for as
long as the Transform stayed in the connection cache.

The exception was only ever used for its message, so store str(error).
That also drops anything else the exception might reference, not only
__traceback__, __context__ and __cause__.

Fixes #112

Keep the BrokenTransform when the transform module cannot be imported

The ImportError branch of Transform._load_transform() returned the
BrokenTransform without storing it in _v_transform. Every accessor that
lazily loads the transform (convert, get_documentation, set_parameters)
then failed with AttributeError on _v_transform instead of using the
BrokenTransform like the register() branch does.
