Enrich public API docstrings for autodoc and IDE help

The docstrings of the most-used testing helpers and layer classes were
thin one-liners: applyProfile documented none of its six parameters,
cleanUpMultiPlugins had no docstring at all, and IntegrationTesting /
FunctionalTesting said only 'Plone version of the ... testing layer'.

Enrich login, logout, setRoles, applyProfile, cleanUpMultiPlugins,
IntegrationTesting and FunctionalTesting with parameter descriptions
(reST field lists) and behaviour notes. No behaviour change, docstrings
only. This is groundwork for an autodoc-generated API reference in the
Plone documentation, and improves IDE help in the meantime.
