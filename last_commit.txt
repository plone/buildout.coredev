Allow anonymous access to @types for the context's own type (#2055)

* Allow anonymous access to @types for the context's own type

The @types service is protected by zope2.View, but check_security
rejected every anonymous request. That breaks Volto's default view
for anonymous visitors, which fetches the schema of the content it
is rendering.

Anonymous users may now read the schema of the context's own
portal_type. Other types, the types list, and field lookups still
require authentication.

Closes #2054

* Trigger RTD build

* Test that field lookups on the context's own type stay closed to anonymous users
