Resolve the deprecated Open Browser keyword at runtime

robotframework-browser 20.6 marks Open Browser as deprecated.  Robot
Framework warns about deprecated keywords even when they sit in an IF
branch that does not run, so every test logged

    Keyword 'Browser.Open Browser' is deprecated.

although the keyword is only used in debug mode.  Calling it through
Run Keyword defers the lookup until the debug branch really runs.

Open Browser stays, because it is the only keyword that pauses on
failure and leaves the browser open.
