Do not use the remote url of a link item in navigation.

Main reasons:

* The main navigation menu does not use the remote url either.  Let's keep these two in sync.
* Until now, only the creator would get the url of the link item itself.  So other editors would have a hard time traversing to the link to edit it.

For more, see https://github.com/plone/Products.CMFPlone/issues/4269
