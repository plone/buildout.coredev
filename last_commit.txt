Remove deprecation warning for `Batch.__len__` again.

Calling this method is simly unavoidable.
When a page template does a `tal:repeat` over a batch, `Products.PageTemplates` calls `list(batch)` and `len(batch)`, both of which invoke calling `__len__`.
You can try this out with `bin/zopepy`:

```
$ bin/zopepy
&gt;&gt;&gt; from plone.base.batch import Batch
&gt;&gt;&gt; len(Batch(range(10), 3))
&lt;console&gt;:1: DeprecationWarning: Use length attribute instead of __len__
3
&gt;&gt;&gt; list(Batch(range(10), 3))
&lt;console&gt;:1: DeprecationWarning: Use length attribute instead of __len__
[0, 1, 2]
```

The deprecation warning was removed in Plone 5.2.3, see https://github.com/plone/Products.CMFPlone/issues/3176
But during the move of the `Batch` class to `plone.base` in Plone 6.0 it was added again.
Compare:

* https://github.com/plone/Products.CMFPlone/commit/2cc25159443759573360af51216bcb9253cc87c1#diff-fa1e7e5e81879e8c4f4485cf8d8204eba6f2677cb9f4e29de4776b0c1f0d4d93L21
* https://github.com/plone/plone.base/commit/6e26a377f7153ea6631a6ad58b7a9008fd3d6e53#diff-316da888fe8d39c68d5e0aee055b3bbfa95d522b4b09fe56b7edb1289bd72f9fR28
