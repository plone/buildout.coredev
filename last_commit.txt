Normalize blob file names and report items imported with errors (#114) (#115)

Export writes each blob under a normalized file name: Unicode NFC, with
path separators, control characters and characters invalid on Windows
replaced, trailing dots and spaces removed, Windows reserved names
prefixed and the name capped at 255 bytes. The file on disk, blob_path
and _blob_files_ now always agree, and a file name can no longer write
outside the export directory. The field's filename keeps its original
value.

On import, load_blob also tries the NFC form of a recorded blob path, so
existing exports whose JSON holds an NFD name for an NFC file import
correctly on byte-exact filesystems.

ContentImporter now records items whose deserialization failed, with the
fields that failed, and reports them as imported with errors;
plone-importer exits with status 1 when there are any. The dropped and
incomplete records are per instance instead of a shared class attribute.

Closes #114
