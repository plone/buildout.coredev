Add Content-Disposition: inline with filename to @@display-file

When @@display-file serves files with allowed inline mimetypes
(images, PDFs, text/plain), browsers had no filename hint, so
"Save As" would use generic names like "document.pdf".

Now sets Content-Disposition: inline; filename*=UTF-8''&lt;name&gt; which
preserves inline display while providing the correct filename.

Fixes #205

Co-Authored-By: Karel Calitz &lt;karel@juizi.com&gt;
