Split the default page overlay closes robot scenario into three tests

After saving the select_default_page form, pat-plone-modal removes the
modal and then reloads the window (displayInModal is false site-wide,
reloadWindowOnClose is on by default).  "overlay should close" only
waits for the modal to leave the DOM, so the next "Go to" on the same
folder collided with that reload and failed with "interrupted by
another navigation".

Cancel and the close button only hide the modal, so each way of closing
now gets its own scenario.

Fixes #4401
