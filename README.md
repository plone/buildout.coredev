# buildout.coredev

This repository contains the development buildout for Plone Core (the backend and classic UI). The current branch is 6.2.

If you are new to Plone core development, start with the official contributor documentation:

- [Plone contributor documentation](https://6.docs.plone.org/contributing/core/index.html)

## Getting started

This project supports two common workflows:

- Buildout-based development with the classic buildout setup.
- Pip and mxdev based development with the Makefile workflow described in [README-make.md](README-make.md).

For the quickest local setup, begin with [README-make.md](README-make.md).

## Development containers and GitHub Codespaces

If you prefer a preconfigured editor environment, see [README-devcontainer.md](README-devcontainer.md) for instructions for VS Code Dev Containers and GitHub Codespaces.
